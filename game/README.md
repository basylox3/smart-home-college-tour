# Папка game

Клади сюда файлы игры, сделанные в Visual Studio Code.

Вариант 1: простая HTML/CSS/JS игра:

```text
game/index.html
game/style.css
game/script.js
```

Вариант 2: несколько игр в папках:

```text
game/college-tour/index.html
game/college-tour/style.css
game/college-tour/script.js

game/lab-quest/index.html
game/lab-quest/assets/...
```

После добавления файлов открой `/game` и нажми `Обновить`.
