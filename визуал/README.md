# Визуальная версия сайта

В этой папке лежит автономная версия сайта колледжа.

Файлы:

- `index.html` — разметка страницы.
- `styles.css` — весь внешний вид и адаптивность.
- `script.js` — меню, карусель, просмотр сцены, фоновые эффекты.
- В секции отзывов можно добавить свой отзыв через форму. Он сохраняется в `localStorage` текущего браузера.

Чтобы посмотреть сайт, откройте `index.html` в браузере.
